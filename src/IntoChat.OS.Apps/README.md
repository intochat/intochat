# IntoChat.OS.Apps

First-party compiled shell apps, one folder per app with its scenarios. An app that belongs to a component lives in that component's `Screens` folder instead (the Aspire app: `src/Components/Aspire/Screens`).

How to test: `dotnet test --project src/IntoChat.OS.Apps.Tests.Unit/IntoChat.OS.Apps.Tests.Unit.csproj`

Documentation: `docs/architecture.md` at the repository root.
