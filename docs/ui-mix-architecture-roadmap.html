UI Architecture Roadmap · C# ↔ FlutterMix + NakedUI

Eliminating the 5-Layer UI Complexity

Why ui/lib/ grew to 274 files across 5 overlapping widget layers — and how unifying C# MixStyle with a single naked_ui + fluttermix primitive layer cuts complexity in half.

274 → ~160
Target Dart files in ui/lib/
42 → 1
Single-file dirs in src/ui/
5 → 2
Widget layers (Primitives + Adapters)
1:1
C# MixStyle ↔ Flutter BoxStyler

1. The Main Source of Complexity

OLD Two Competing UI Paradigms + 5 Overlapping Layers

Every control (e.g. Toggle, Select, Card, Toast) was built 3 to 5 times because declarative DigitalBrain.UI nodes and stateful IntoChat.OS.Modules.UI neurons never shared one primitive layer or style DSL:

1. src/nodes/toggle_switch_view.dart + switch.dartDeclarative JSON
2. src/ui/toggle/toggle_widget.dartStateful UI Neuron
3. src/components/toggle/ui_toggle.dartLegacy Component
4. src/design/tokens.dart vs src/theme/ui_tokens.dart2 Design Systems
5. src/lumen/ + src/shell_icon.dart + src/theme/ui_icon.dart3 Icon Locations

NEW One C# MixStyle Contract → One Flutter Primitive Layer

C# mirrors fluttermix directly via a fluent MixStyle record. Both declarative nodes and stateful UI neurons become thin 10-line adapters over one shared primitive set:

C# Domain / Screen (DigitalBrain.UI)MixStyle + Typed Signals
↓ JSON wire contract (style + props + emit)
Thin Adapters (src/nodes/ + src/widgets/neuron/)Binding only — 0 styling
↓ 1:1 prop & style pass-through
Primitives (src/primitives/*.dart)naked_ui + fluttermix
↓ reads single token source
Theme (src/theme/)UiColors + UiTokens

2. Code Examples: Old vs. New (C# ↔ FlutterMix)

OLD C# Ad-hoc strings, raw emits, no hover/press/layout styling

// Old SettingsViewRenderer.cs — stringly-typed emit, no Mix styling
new NavItem(
    key: $"nav-{entry.SectionId}",
    label: entry.Title,
    icon: entry.Icon,
    selected: isSelected,
    // Fragile string emit — broke silently when signal changed!
    emit: AppSignals.Emit("settings", "navigate", entry.SectionId)
);

// Old Button — limited to fixed enum, cannot express padding/radius/hover
new Button("save", "Save Changes", Sends(new SaveSettings()))

NEW C# Fluent MixStyle mirroring FlutterMix + Typed Signals

// New C# — mirrors fluttermix BoxStyler + naked_ui interaction states
new Button(
    key: "save",
    label: "Save Changes",
    emit: Sends(new SaveSettings()),
    style: Mix.Style()
        .Tone(UiTone.Accent)
        .Padding(x: 16, y: 10)
        .Radius(8)
        .Elevation(UiElevation.Raised)
        .OnHover(s => s.Tone(UiTone.AccentStrong))
        .OnPress(s => s.Scale(0.97))
        .Motion(UiMotion.Snappy)
);

OLD Flutter Duplicated Material widgets + hardcoded colors

// Old checkbox_widget.dart — raw Material Checkbox + InkWell
InkWell(
  borderRadius: BorderRadius.circular(8),
  onTap: isEnabled ? () => invoke('Toggle') : null,
  child: Row(children: [
    Checkbox(value: isChecked, onChanged: ...),
    Text(label, style: TextStyle(color: c.textStrong)),
  ]),
);
// Plus a SECOND copy in nodes/check_box_view.dart!

NEW Flutter 10-line Adapter → Single src/primitives/checkbox.dart

// Both nodes/check_box_view.dart AND widgets/neuron/checkbox_widget.dart:
return UiMixCheckbox(
  value: isChecked,
  enabled: isEnabled,
  label: label,
  style: UiStyleData.fromJson(node.style), // 1:1 from C# Mix.Style()
  onChanged: (_) => onToggle(),
);

// Inside src/primitives/checkbox.dart (single source of truth):
NakedCheckbox( // a11y + keyboard + focus + hover + press
  child: Box(style: UiStyleMapper.boxStyler(context, style), ...),
);

WIRE CONTRACT Compact JSON produced by C# Mix.Style() and consumed by UiStyleMapper

{
  "kind": "button",
  "key": "save",
  "label": "Save Changes",
  "command": { "signal": "settings.save" },
  "style": {
    "tone": "accent",
    "px": 16, "py": 10, "radius": 8,
    "elevation": "raised",
    "motion": "snappy",
    "hover": { "tone": "accentStrong" },
    "press": { "scale": 0.97 }
  }
}

3. Execution Roadmap

Phase 1 — Retire forui & Legacy components/kit/ DONE

  • Removed forui, forui_lucide, and sugar from pubspec.yaml.
  • Deleted lib/src/components/kit/ and flattened all 15 primitives into lib/src/primitives/*.dart (button.dart, checkbox.dart, toggle.dart, tabs.dart, surface.dart, etc.).

Phase 2 — Flatten ui/lib/src/ Folder Tree DONE

  • Folded the 42 single-file dirs in src/ui/*/ into src/nodes/*_view.dart.
  • Consolidated src/models/ + src/signals/ → src/runtime/models/ (with barrel models.dart) and src/voice_input/ + src/voice_mode/ → src/widgets/voice/ (with barrel voice.dart).
  • Merged src/design/tokens.dart into src/theme/ui_tokens.dart as the single token source of truth.

Phase 3 — C# Mix.Style() Fluent DSL ↔ Flutter UiStyleMapper DONE

  • Added fluent Mix.Style() / UiStyle builder & immutable record in DigitalBrain.UI (Tone, Typography, Elevation, Icon, Motion, Padding, Gap, Radius, Scale, plus OnHover/OnPress/OnFocus) with compact JSON wire serialization and backward-compatible string presets.
  • Wired UiStyleMapper in src/primitives/style.dart and src/nodes/button.dart to map state overrides, elevation shadows, Inter typography, and scale directly onto fluttermix BoxStyler + naked_ui widget states.

Phase 4 — Retire Remaining Legacy Material & Duplicate components/ DONE

  • Promoted UiMixInfoBar and UiMixProgress into src/primitives/ and migrated all remaining callers off legacy wrappers onto src/primitives/ + src/nodes/*_view.dart.
  • Deleted duplicate legacy wrappers src/components/toggle/ui_toggle.dart, button/ui_neuron_button.dart, button/ui_neuron_select.dart, infobar/ui_info_bar.dart, and progress/ui_progress.dart along with their empty directories.

Phase 5 — OS Apps Mix.Style() Adoption DONE

  • Extended DigitalBrain.UI node style parity to Surface, Card, and IconButton (with regenerated node_models.dart / showcase_catalog.json and Flutter Mix adapters in src/nodes/{surface,card,icon_button}.dart + src/primitives/surface.dart).
  • Added OsMixStyles semantic presets and fluent .Style(...) builders across IntoChat.OS.UI (Kit, ButtonBuilder, IconButtonBuilder, CardBuilder, SurfaceBuilder) so every Kit button, icon button, card, and surface emits typed Mix.Style() wire JSON by default.
  • Migrated all flagship OS apps and shipped units onto fluent Mix.Style() with 0 legacy string style literals remaining in src/IntoChat.OS.Apps/ and src/Modules/Workspace/Files/: Ino, Engineer, Settings, Files, Desktop / Catalog, Creator, Friends, Tasks, Data, Gallery, and all 7 shipped micro-app units (HelloWorld, FxRatesMonitor, WorkNotesOrganizer, GithubIssueTriager, XWatch, WebhookRelay, WebWatch).
