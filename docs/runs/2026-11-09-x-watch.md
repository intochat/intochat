## How to run it live

1. Start the AppHost locally.
2. Create an `http@1` connection with `allowedHosts: ["api.x.com"]` (with a bearer for the X API), or point it at a local stub host.
   If you use a stub, the unit must GET that host instead.
3. Say the sentence to Ino.
4. Approve the SynapseStaged card in the OS bar. Check that its sentence names http, 6m and the view.
5. Open the Creator, watch the pulse (`time.tick -> x.polled -> synapse.view-changed`) and the badge.
6. Say "change it" (the badge red over 10), confirm that no new consent is asked, and watch the next tick.
Record anything that fails as a fix task.
